# Context Aware Idiom Translation System (CAITS)

The Context Aware Idiom Translation System (CAITS) is a web-based application designed to detect and translate idiomatic expressions based on their contextual meaning. Traditional translation systems often fail to interpret idioms correctly due to their non-literal nature. This system overcomes that limitation by analyzing context and providing meaningful translations.


## Objectives

1 Detect idioms in user-input sentences
2 Distinguish between literal and figurative meanings
3 Provide accurate contextual translations
4 Improve understanding of idiomatic expressions


## Technologies Used

* Programming Language: Python
* Framework: Flask
* Frontend: HTML, CSS, JavaScript
* Database: CSV / SQLite
* Libraries: Pandas, Regex, Transformers (HuggingFace)


##  Features

* Idiom detection using dataset
* Context-aware translation
* User login and registration system
* Translation history tracking
* Example idioms with meanings
* Voice input support

##  How to Run the Project

1. Install Python
2. Install required libraries:

   pip install -r requirements.txt
   
3. Run the application:

   python main.py
   
4. Open browser and go to:

   http://127.0.0.1:5000/
